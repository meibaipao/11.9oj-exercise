# 第 27 题：计算分段函数

## 📝 题目描述
输入一个浮点数 `a`，根据 `a` 的不同取值范围，计算并输出 `x` 的值。

## 💡 解题思路
1. 使用 `float` 或 `double` 定义变量以保留小数。
2. 使用 `if-else if-else` 结构判断 `a` 的区间：
   - 如果 `a <= 110`，按公式 1 计算；
   - 如果 `a <= 210`，按公式 2 计算；
   - 其他情况按公式 3 计算。
3. 使用 `printf("%.2f\n", x);` 保留两位小数输出结果。

## 💻 核心代码片段
```c
if (a <= 110) {
    x = 0.50 * a;
} else if (a <= 210) {
    x = 0.50 * 110 + 0.55 * (a - 110);
} else {
    x = 0.50 * 110 + 0.55 * 100 + 0.70 * (a - 210);
}
